# External Libraries (JARs)

Place the MySQL JDBC Driver here:
- **File:** `mysql-connector-j-8.3.0.jar` (or MySQL Connector/J 8.x/9.x)
- **Maven Repository Direct Download:**
  `https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.3.0/mysql-connector-j-8.3.0.jar`

### PowerShell Command to Download:
```powershell
Invoke-WebRequest -Uri "https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.3.0/mysql-connector-j-8.3.0.jar" -OutFile "lib/mysql-connector-j-8.3.0.jar"
```
